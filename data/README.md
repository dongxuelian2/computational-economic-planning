# Data directory

Do not commit downloaded raw data unless redistribution is explicitly permitted. Record dataset citations, versions, original source URLs, units, release dates, and preprocessing scripts. Use small synthetic fixtures for automated tests.

- Eurostat FIGARO: https://ec.europa.eu/eurostat/en/web/esa-supply-use-input-tables/database
- Chinese province-level MRIO: https://doi.org/10.6084/m9.figshare.28973396.v3
